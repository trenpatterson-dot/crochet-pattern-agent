# StitchFlow Tutorial Mapping Ideas

## Purpose

This document tracks beginner crochet pain points and maps them to useful tutorial guidance.

Goal:

Help beginners start and finish projects with less overwhelm.

The system should eventually recommend:
- tutorials
- stitch help
- beginner warnings
- common mistake guidance
- technique support

based on the actual project being recommended.

---

# Core Principle

The goal is NOT:

> “send random YouTube links.”

The goal IS:

> “help beginners find the exact help they need before they get frustrated.”

---

# Beginner Pain Points

## Starting Problems

Beginners often struggle with:

- making the first chain
- keeping tension even
- understanding abbreviations
- counting stitches
- reading patterns
- understanding rows vs rounds
- choosing yarn
- choosing hook size
- understanding gauge
- identifying stitch placement
