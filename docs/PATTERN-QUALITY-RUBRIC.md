# StitchFlow Pattern Quality Rubric

## Purpose

This rubric defines the minimum quality standard for original StitchFlow Labs crochet patterns before they are emailed to users.

Goal:

Help overwhelmed beginners successfully complete projects.

---

## Required Pattern Sections

Every original pattern MUST include:

- Project title
- Short project overview
- Skill level
- Yarn weight
- Hook size
- Gauge guidance
- Finished size estimate
- Materials list
- Abbreviations
- Beginner confidence score
- Exact stitch types used
- Starting chain count OR round setup
- Row-by-row OR round-by-round instructions
- Stitch counts where appropriate
- Finishing steps
- Pattern notes
- Beginner troubleshooting guidance
- Tutorial support/search guidance

---

## Automatic Failure Conditions

Reject patterns that:

- use vague wording only
- skip stitch counts
- skip row/round labels
- skip materials
- skip abbreviations
- skip finishing steps
- skip tutorial guidance
- rely heavily on “continue until desired size”
- rely heavily on “repeat as needed”
- rely heavily on “work in pattern”
- provide unclear shaping instructions
- provide impossible stitch counts
- provide incomplete construction steps

---

## Beginner Success Signals

Patterns score higher when they:

- use basic stitches
- include stitch counts
- include row labels
- explain shaping clearly
- provide tutorial guidance
- finish quickly
- use common yarn/tools
- explain common mistakes
- include tension guidance
- include troubleshooting notes
- include realistic beginner pacing

---

## Beginner Confidence Scoring

### High

Pattern:

- uses mostly beginner stitches
- has clear rows/rounds
- has stitch counts
- has tutorial guidance
- uses common materials
- avoids complex shaping

### Medium

Pattern:

- introduces some intermediate concepts
- may require counting focus
- may include shaping or color changes
- still has tutorial guidance and structure

### Low

Pattern:

- uses advanced shaping
- requires advanced counting
- has difficult assembly
- uses uncommon techniques
- likely frustrates new beginners

---

## Email Rendering Requirements

Every original pattern email card must include:

- Title
- Beginner Confidence
- Start Here
- Search YouTube Tutorial
- Materials
- Abbreviations
- Pattern Instructions
- Pattern Notes
- Feedback section

Never render:

- fake buttons
- empty links
- debug labels
- internal QA wording
- incomplete cards

---

## Tutorial Quality Rules

Tutorial guidance should:

- help beginners start faster
- link to likely useful searches
- avoid assuming prior knowledge
- mention difficult techniques early

Examples:

- magic ring tutorial
- invisible decrease tutorial
- color change tutorial
- beginner tension help
- stitch counting help

---

## Future Expansion

Future scoring inputs may include:

- user success rate
- confusion reports
- abandonment indicators
- tutorial completion
- common beginner failure points
- materials availability
- time-to-finish estimates

---

## Core Product Principle

The goal is NOT:

> generate crochet patterns with AI.

The goal IS:

> help beginners successfully finish projects without feeling overwhelmed.
